# Лендинг для малого бизнеса (шаблон на продажу)

Одностраничный сайт для барбершопа. Чистый HTML/CSS/JS: без конструкторов, без сервера, без ежемесячной платы.
Сайт адаптирован под телефоны, есть форма записи (заявки уходят в Telegram или WhatsApp) и анимации.

## Файлы
- `index.html` — тексты, услуги, цены, отзывы
- `style.css` — оформление (цвета меняются в самом верху, блок `:root`)
- `script.js` — контакты и настройки (блок `CONFIG` в самом верху)

## Как переделать под нового клиента (30–60 минут)
1. В `index.html` поменяйте название, тексты, услуги, цены, адрес.
2. В `script.js` → `CONFIG` укажите телефон, Telegram и WhatsApp клиента.
3. В `style.css` → `--accent` поставьте фирменный цвет клиента.
4. Фото мастеров: в `index.html` у `.master__photo` замените букву на
   `style="background-image:url('img/alex.jpg')"`, а файлы положите в папку `img/`.
5. Карта: откройте yandex.ru/map-constructor, поставьте метку и вставьте полученный `<iframe>` вместо блока `.map`.

## Заявки в Telegram (по желанию)
1. Напишите @BotFather → `/newbot` → скопируйте токен в `CONFIG.botToken`.
2. Напишите своему боту любое сообщение, затем откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и скопируйте `chat.id` в `CONFIG.chatId`.
3. Готово: заявки с формы будут приходить в Telegram.
   Если бот не настроен, форма откроет WhatsApp с уже готовым текстом заявки.

## Бесплатная публикация (GitHub Pages)
Settings → Pages → Branch: `main` / root → Save. Через минуту сайт будет доступен по адресу
`https://<ваш-логин>.github.io/<репозиторий>/`. Свой домен (~200–300 ₽/год) подключается там же.
