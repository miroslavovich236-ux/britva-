# Лендинг для малого бизнеса (шаблон на продажу)

Одностраничный сайт для барбершопа. Только HTML и CSS, без JavaScript, конструкторов, сервера и ежемесячной платы.
Сайт адаптирован под телефоны, есть мобильное меню на CSS и форма записи (заявки приходят на почту).

## Файлы
- `index.html` — тексты, услуги, цены, отзывы, телефон, ссылки на Telegram (`t.me/...`) и WhatsApp (`wa.me/...`)
- `style.css` — оформление (цвета меняются в самом верху, блок `:root`)

## Как переделать под нового клиента (30–60 минут)
1. В `index.html` поменяйте название, тексты, услуги, цены, адрес.
2. В `index.html` найдите (Ctrl+F) `79990000000` и `username` и замените на телефон и Telegram клиента.
3. В `style.css` → `--accent` поставьте фирменный цвет клиента.
4. Фото мастеров: в `index.html` у `.master__photo` замените букву на
   `style="background-image:url('img/alex.jpg')"`, а файлы положите в папку `img/`.
5. Карта: откройте yandex.ru/map-constructor, поставьте метку и вставьте полученный `<iframe>` вместо блока `.map`.

## Заявки с формы на почту (без JavaScript)
Форма отправляется через бесплатный сервис formsubmit.co.
1. В `index.html` в строке `action="https://formsubmit.co/your@email.ru"` укажите почту клиента.
2. Опубликуйте сайт и один раз отправьте тестовую заявку.
3. На эту почту придёт письмо с подтверждением: нажмите в нём кнопку. После этого все заявки будут приходить на почту.

## Бесплатная публикация (GitHub Pages)
Settings → Pages → Source: «Deploy from a branch» → Branch: `claude/vibe-coding-website-elvdkm`, папка `/ (root)` → Save. Через минуту сайт будет доступен по адресу
`https://<ваш-логин>.github.io/<репозиторий>/`. Свой домен (~200–300 ₽/год) подключается там же.
